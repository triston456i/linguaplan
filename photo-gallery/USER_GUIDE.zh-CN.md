# 家庭相册使用指南

本指南面向**使用者**（家人、朋友），介绍如何登录、浏览和查看照片与视频。
网站界面目前是英文的，指南会在每个按钮后面用中文标注它的意思，方便对照。

如果你是负责搭建这个网站的人，请参考仓库里的 `README.md`（安装、配置、添加账号等技术说明）。

## 1. 登录

1. 打开管理员提供给你的网址。
2. 会看到一个深色背景的登录框，标题是 **Photo Gallery**。
3. 在 **Username**（用户名）栏输入你的用户名。
4. 在 **Password**（密码）栏输入密码。
5. 点击蓝色的 **Sign in**（登录）按钮。

如果用户名或密码错误，输入框上方会出现红色提示文字。多次输错后，系统会暂时限制登录尝试，稍等几分钟再试即可。

> 忘记密码？网站没有"忘记密码"功能，需要请管理员帮你重设，见下方常见问题。

## 2. 浏览相册（文件夹）

登录后会看到顶部的导航栏：

- 左上角是**路径导航**，最开始只显示 **Home**（首页）。
- 右上角是 **Sign out**（退出登录）按钮。

页面主体分两部分：

- 第一行是**文件夹卡片**，每个卡片前面有一个文件夹图标 📁，点击即可进入该文件夹查看里面的内容。
- 下面是**缩略图网格**，显示当前文件夹里的照片和视频。视频缩略图上会有一个白色的播放三角形 ▶ 标记，用来和照片区分。

进入子文件夹后，顶部路径导航会显示完整路径，例如 `Home / 家庭旅行 / 2024年 海边`，点击其中任意一段可以直接跳回那一层。

如果某个文件夹里没有照片或视频，页面会显示"该文件夹中没有照片或视频"的提示。

## 3. 查看照片

点击任意一张照片缩略图，会打开全屏查看模式：

- 照片会尽量放大显示，同时保持原始比例。
- 屏幕左右两侧有圆形箭头按钮 ‹ ›，点击可以切换到上一张 / 下一张。
- 也可以直接使用键盘的 **←** **→** 方向键切换。
- 右上角的 **×** 按钮用来关闭查看模式；按键盘 **Esc** 键或点击图片以外的黑色区域也可以关闭。

## 4. 播放视频

点击带有播放图标 ▶ 的缩略图，会在同一个全屏查看窗口中播放视频：

- 视频下方会出现标准的播放控制条，可以播放/暂停、拖动进度条、调整音量、全屏播放。
- 支持边播放边拖动进度（不需要等视频完全下载完才能跳转）。
- 用左右箭头按钮或顶部关闭按钮，可以切换到其他照片或视频、或退出查看模式。

支持的视频格式：mp4、mov、m4v、webm、mkv、avi、wmv、flv、mpg/mpeg、3gp。

## 5. 退出登录

看完之后，点击右上角的 **Sign out**（退出登录）按钮即可安全退出。如果是在共用设备（比如客厅电脑、平板）上查看，建议看完及时退出。

## 常见问题

**忘记密码怎么办？**
网站目前没有自助改密码功能，请联系负责搭建这个网站的家人，让他/她重新设置一个新密码给你。

**视频打不开或放不出来？**
先确认视频格式是否在上面列出的支持列表里。如果格式正确但仍然打不开，换一个浏览器或设备试试；也可能是网络不稳定，刷新页面重试。

**在家以外的地方打不开网站？**
这取决于管理员为远程访问做的设置（比如是否配置了远程访问链接）。如果链接一直打不开，请联系管理员确认。

**第一次打开某个文件夹，照片加载比较慢？**
属于正常现象：系统第一次浏览某个文件夹时需要生成缩略图，之后再次打开同一文件夹会快很多。

**可以把照片或视频保存到自己的手机/电脑吗？**
目前网站本身没有专门的"下载"按钮，可以用浏览器自带的保存图片/长按保存等方式另存。

**忘记网址了怎么办？**
请向搭建网站的家人索要网址，建议把它加到浏览器收藏夹或手机主屏幕，方便下次直接打开。
